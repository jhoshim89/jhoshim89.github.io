개인정보처리방침 (Privacy Policy)

적용 대상: SosoFind SNS (@soso.find2026 / @soso.salim2026) · 시행일: 2026-11-20

1. 수집·접근하는 Google/YouTube 데이터

SosoFind SNS는 운영자 본인의 Google/YouTube 계정 인증(OAuth 2.0)을 통해 아래 권한 범위(Scope)에 한해 접근합니다.

  • https://www.googleapis.com/auth/youtube.upload: 운영자가 승인한 동영상·쇼츠 업로드
  • https://www.googleapis.com/auth/youtube: 본인 채널의 동영상 제목·설명·공개 상태 및 댓글 관리
  • https://www.googleapis.com/auth/youtube.readonly: 본인 채널 기본 정보 및 업로드 목록 조회

2. 이용 목적 및 제한

접근한 데이터와 인증 토큰은 오직 운영자 본인 소유 유튜브 채널의 콘텐츠 업로드, 상태 점검, 댓글 관리 목적으로만 사용됩니다. 외부 일반 사용자의 개인정보를 수집하거나 제3자에게 판매·제공·공유하지 않으며, 광고 타겟팅 또는 AI 학습에 사용하지 않습니다.

3. 보관 및 보안

OAuth 클라이언트 정보 및 토큰은 외부 공개 저장소나 웹 서버에 두지 않고 운영자의 로컬 환경(접근 권한 chmod 600 제한 파일)에만 보관합니다.

4. Google API 사용자 데이터 정책 준수

SosoFind SNS의 Google API로부터 전달받은 정보 이용은 제한적 사용(Limited Use) 요건을 포함하여 Google API Services User Data Policy를 준수합니다.

5. 권한 철회 및 데이터 삭제 요청

언제든지 Google 계정 권한 관리 페이지에서 SosoFind SNS의 접근 권한을 철회하거나, soso.find2026@gmail.com으로 로컬 토큰 및 관련 기록 삭제를 요청하실 수 있습니다.
